PuzzleFlow

PuzzleFlow is a simple interactive puzzle website where users can scroll through different types of puzzles, solve them, and keep track of their progress.

The main idea behind this project is to make puzzle solving more engaging by presenting different puzzles in a continuous feed instead of making users select a particular category.

Features
Sudoku puzzles
Word Search puzzles
Anagram puzzles
Riddles
Logic puzzles
Aptitude puzzles
Detective puzzles
Zebra puzzles
Code Breaker puzzles
Instant answer checking
Correct answer shown for incorrect attempts
Skip option
Score tracking
Streak tracking
Solved puzzle counter
Progress saved using Local Storage
Responsive design for different screen sizes
Technologies Used
HTML5
CSS3
JavaScript

How It Works

When the website is opened, puzzles are displayed one after another. Different puzzle types are automatically selected so that the user gets a variety of challenges while scrolling.

The user can enter or select an answer and click the Check Answer button. The website immediately shows whether the answer is correct. The score and streak are updated based on the user's performance.

The Skip button allows the user to move to another puzzle without solving the current one.
